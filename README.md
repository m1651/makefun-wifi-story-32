bounty on make.fun ($2 reward).

## The entry

> Dave moved out. WiFi stayed.

Character count: **28** (single line, within the 1–32 character limit).

## How it works

`main.py` holds the Wi-Fi name as a constant, validates it (non-empty,
single line, 1–32 characters), and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/wifi-story-32-output python3 main.py
cat /tmp/wifi-story-32-output/entry.txt
```
